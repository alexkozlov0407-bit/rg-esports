## ⚡ Features & Interactivity

- **MMR Ladder & Dynamic Tier Matching**: Real-time slider (0 to 2200+ MMR) instantly mapping players to their corresponding RG roster, captain, coach, and tier profile.
- **10 Captained Competitive Squads**: Split across North American (NA) and European (EU) divisions:
  - *NA High Tiers*: RG Dynasty (C2-C3), RG Solar (C1-C2), RG Nightshift (D3-C1), RG Province (D1-D2)
  - *EU High Tiers*: RG Horizon (GC2-SSL), RG Zenith (GC1-GC2), RG Mainstream (GC1-GC2), RG Twilight (C1-C3), RG Rush (D3-C1)
- **The RG Academy Pipeline**:
  - **Diamond Academy** & **Platinum Academy** development pipelines.
  - Dedicated academy leadership under `[NA] Tay` and management.
  - Integration with community coach **Jonh Magazoni** and Founder **[NA] Vey †**.
- **Interactive Staff Hierarchy & Dispute Protocol**:
  - Live constitutional escalation engine matching situations (Player vs Player, Sub Disputes, Roster Changes, Rule Violations) to the exact staff tier.
  - Division between Moderation Staff Roster and Community/Content Roster.
- **Live Social Media Radar**:
  - **Discord**: Real-time widget fetching member count, presence, and direct join invites.
  - **YouTube**: Dynamic playlist & Shorts integration with recruitment breakdown modals.
  - **TikTok & X**: Live feed trackers with quick-follow cards.
- **Interactive Tryout & Partnership Portals**:
  - Form validation with dynamic Discord scouting ticket generator and 1-click clipboard exporter.
  - Partnership verification portal matching RG Esports' 50+ member minimum criteria.
- **Web Audio Sound Engine**: Subtle synthesizer feedback on interactive buttons, tabs, sliders, and tryout submissions.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Server Components & Route Handlers)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with custom golden esports glow themes
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations & Effects**: Custom CSS keyframes, glassmorphism backdrop filters, audio synthesis
- **Hosting & CI/CD**: [Vercel](https://vercel.com/) with automated branch previews and edge deployment

## 🚀 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/alexkozlov0407-bit/rg-esports.git
   cd rg-esports
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Production Build**:
   ```bash
   npm run build
   ```

## 📜 History of RG Esports

- **2022 (Revenge Esports)**: Started as a grassroots Rocket League community, growing to nearly 1,000 members and achieving **Top 185 in a European RLCS Open**.
- **2026 (Dash Esports)**: Rebuilt community to 250+ members across NA and EU competitive rosters.
- **Late 2026 (Republic of Golds - RG Esports)**: Complete identity rebrand focused on winning, structured academy progression, captained team autonomy, and league championships.
