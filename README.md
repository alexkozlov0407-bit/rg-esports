# ⚡ Voltix Esports (VLTX) — Official Website

Official modern esports website and media hub for **Voltix Esports (VLTX)**, featuring live social subscriber counters, YouTube video clip showcases, Twitch stream indicators, Discord live server integration, interactive team roster, giveaway countdown, roster PR requirements matrix, and booster perks.

---

## 🚀 Quick & Easy Deployment Options

This website is built with clean modern HTML5, Tailwind CSS, Lucide icons, and optimized vanilla JavaScript. It requires **no complex build steps**, making deployment fast, reliable, and free on any hosting platform.

### Option 1: 1-Click Interactive Deploy Script
In your terminal, simply run:
```bash
./deploy.sh
```
Follow the interactive prompt to deploy to **Vercel**, **Netlify**, **GitHub Pages**, or launch a local preview.

---

### Option 2: Deploy to Vercel (Recommended — 30 Seconds)
1. Run in your terminal:
   ```bash
   npx vercel --prod
   ```
2. Follow the 2-step prompt (hit Enter to accept default settings).
3. Your website will be live with a free custom SSL URL (e.g. `https://voltix-esports.vercel.app`)!

---

### Option 3: Deploy to Netlify (Drag-and-Drop or CLI)
- **Method A (Zero Terminal / Drag & Drop)**:
  1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
  2. Drag and drop this entire project folder into the browser window.
  3. Done! Your website goes live immediately.
- **Method B (CLI)**:
  ```bash
  npx netlify deploy --prod --dir=.
  ```

---

### Option 4: Deploy to GitHub Pages (Free Permanent Hosting)
1. Commit and push this directory to your GitHub repository:
   ```bash
   git add .
   git commit -m "Voltix Esports official website"
   git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
   git push -u origin main
   ```
2. Go to your repository on GitHub:
   - Click **Settings** > **Pages**
   - Under **Build and deployment > Branch**, select `main` and `/ (root)`
   - Click **Save**
3. Your site will be published at `https://<YOUR_USERNAME>.github.io/<YOUR_REPO_NAME>/`

---

## 💻 Local Preview & Testing

To preview the website locally on your computer:
```bash
python3 -m http.server 3000
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.
